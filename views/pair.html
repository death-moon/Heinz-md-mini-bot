Instructions

  1. Entrez votre numéro de téléphone avec l'indicatif pays
  2. Configurez les paramètres selon vos préférences
  3. Cliquez sur "Générer le Code de Pairing"
  4. Ouvrez WhatsApp sur votre téléphone
  5. Allez dans Paramètres > Appareils liés
  6. Appuyez sur "Lier un appareil"
  7. Sélectionnez "Lier avec le numéro de téléphone à la place"
  8. Entrez le code de pairing affiché
